**版本**：V1.0 ｜ **编制日期**：2026-11-06 ｜ **依据**：《需求分析方案 V1.0》（AC 编号）、《详细项目设计方案 V1.0》（模块编号）、现有代码基线（错误码 1001-5000、6 工具、四层防线、30 条评测集）

## 六、故障场景用例（TC-D，20 条）

| 编号 | 故障注入 | 预期结果与量化指标 |
| --- | --- | --- |
| D-01~03 | LLM 超时（>30s）/返回 5xx/返回畸形 JSON | SSE 流内 event:error，错误码 3001，用户侧中文提示；**不崩溃、无半截脏数据入库** |
| D-04 | LLM 供应商切换（openai→mock 热切换） | 切换后下一问正常，切换耗时 <1s |
| D-05~06 | PostgreSQL 断连/慢查询（>5s） | 1002/5000 友好提示；连接池自动恢复，恢复后首请求 <3s |
| D-07 | Redis 不可用 | 降级为无缓存直查，功能不中断 |
| D-08~10 | OCR 服务超时/崩溃/返回乱码 | 任务转"存疑"态转人工，不阻塞提交主流程 |
| D-11~12 | 发票查验 API 超时/Key 失效 | **fail-closed**：validated 不得置 true，后续 submit 被 4002 拦截 |
| D-13~14 | SSE 客户端中途断开/网络抖动重连 | 服务端终止生成并落库已完成部分，无孤儿任务堆积 |
| D-15 | 对象存储（MinIO）不可用 | 上传失败返回 5000 中文提示，已入库记录回滚 |
| D-16 | 磁盘写满（审计日志目录） | 告警且拒绝写操作而非静默丢弃 |
| D-17 | 知识库索引损坏 | 重建索引指令可用，重建后检索命中率恢复 |
| D-18 | 并发 50 用户同时问答 | 错误率 <1%，P95 首 token <3s |
| D-19 | 进程重启 | 会话与草稿从 DB 恢复，进行中任务标记中断 |
| D-20 | 时钟回拨（NTP 校正） | JWT 校验容错，审计时间戳单调性校验告警 |

## 八、量化出口标准（全部满足方可验收）

1. TC-A 通过率 ≥98%（40 例中最多 1 例非阻断缺陷）；
2. TC-B、TC-C 通过率 **100%**（31 例安全用例零失败，含 B/C 全部）；
3. TC-D 通过率 ≥95%，D-11 fail-closed、D-03 无脏数据两条**必须通过**；
4. 压测 PT-01/PT-02 全部达标；
5. 核心模块行覆盖率 ≥80%，安全相关模块（security/tools/audit）≥90%；
6. P0 缺陷 =0，P1 缺陷 ≤2 且有规避方案；
7. 遗留缺陷全部录入缺陷库并给出修复排期。

## 九、缺陷等级定义

| 等级 | 定义 | 处理要求 |
| --- | --- | --- |
| P0 | 安全泄漏/越权成功/资金数据错误/主流程阻断 | 立即修复，阻断发布 |
| P1 | 功能错误有替代路径/降级失效 | 修复后回归，48h 内 |
| P2 | 非关键功能异常/体验问题 | 排期修复 |
| P3 | 建议/文案/样式 | 版本内择机 |
